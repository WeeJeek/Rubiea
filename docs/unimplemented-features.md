# Unimplemented Features

## `GEM-001` 供货伙伴合作规则

- **范围：** 利润公式、可扣费用、审批、垫付、定价权、所有权、损失、退货与结算。
- **验收：** 双方对 [供货伙伴问题清单](supplier-questionnaire.md) P0 合作问题形成书面一致答案。
- **依赖：** 供货伙伴确认。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-002` 可追踪库存

- **范围：** 供货前分包与收货后编号、称重、拍照、分类和文件关联。
- **验收：** 任一商品均可从库存记录追溯到供货批次、来源声明、处理声明、价格与交易结果。
- **依赖：** 供货伙伴执行寄出前分包；销售方准备基础测量与拍摄工具。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-003` 商品定名与送检

- **范围：** 鉴定绿色材料，区分供货方声明与实验室结论，选择 B2B/B2C 送检商品。
- **验收：** 未经鉴定的绿色材料不称祖母绿；B2C 候选裸石拥有可核验的独立报告。
- **依赖：** 编号库存、鉴定预算和实验室选择。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-004` B2B 温线索销售

- **范围：** 按商品偏好分组 10 位温线索，准备三个独立货盘，优先联系 5 位。
- **验收：** 每位线索收到匹配其采购偏好的英文联系内容，并记录回复、需求和下一步。
- **依赖：** 编号、价格、处理状态与看货流程。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-005` 单品牌双入口

- **范围：** 先在桌面端复核品牌视觉方向板，确认主视觉方向；再设计 B2C 默认首页、公开 `For Trade` 页面、私密批发目录及分渠道社交沟通。
- **验收：** 主视觉方向经销售方明确确认；消费者能看到专业贸易能力但无法看到批发价格；专业买家能直达交易信息与预约入口。
- **依赖：** 商品资料、内容资产与网站预算。
- **待复核资料：** `docs/brand/rubiae-visual-directions-preview.png`；仅供方向比较，图内宝石、产地和证书均为虚构排版示意，不得用于宣传。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)与 [Rubiae 品牌基调与表达系统](rubiae-brand-foundation.md)。

## `GEM-006` 宝石销售知识冲刺

- **范围：** 每周四小时，结合现货观察、英文术语、处理与合成、报告阅读、品质描述和原石风险。
- **验收：** 销售方能用英语准确介绍商品并明确何时需要送检或拒绝作出保证。
- **依赖：** 现货编号与学习资料。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-007` 精选首饰合作试销

- **范围：** 保留伙伴品牌的小规模现成首饰合作，验证消费者组合需求。
- **验收：** 上线前明确所有权、定价、分成、品牌署名、退换货、维修和客户资料归属。
- **依赖：** 首饰伙伴确认。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-008` 试销边界与成功指标

- **范围：** B2C 价格带、看货地点与安全、付款交付、运营职责和试销指标。
- **验收：** 所有开放项都有单一、可执行的书面决定。
- **依赖：** 销售方回答与合作方输入。
- **设计来源：** [Rubiae品牌经营基本信息](rubiae-business-basics.md)。

## `GEM-009` 自愿里程碑分享

- **范围：** 顾客购买后获得其宝石的分享照片与可编辑人生节点文字卡，可选择公开发布、匿名授权 Rubiae 收录或完全不分享。
- **UX 决定：** 三种选择享受同等品牌礼遇；不以折扣或其他利益交换公开发帖；Rubiae 转发前取得与购买授权分离的明确发布授权。
- **验收：** Instagram 分享素材和可选 X 文案可直接使用；顾客能清楚选择公开、匿名或不分享；未授权故事不会发布；流程不要求提交人生节点证明。
- **依赖：** 商品摄影、分享卡模板、隐私说明、发布授权记录和社交账号。
- **设计来源：** [领域词汇](../CONTEXT.md)与 [Rubiae 品牌基调与表达系统](rubiae-brand-foundation.md)。

## `GEM-010` 消费者定制切磨研究

- **范围：** 评估消费者选择切磨原石及期望方向、由 Rubiae 协调泰国专业切割师完成切磨的未来服务；当前不作为现有 B2C 服务宣传。
- **验收：** 确认候选切割师、作品与资质核验、原石可行性评估、报价、预计损耗、失败风险、处理时限、运输保险、验收、退款争议与各方责任；据此形成继续或放弃该服务的决定。
- **依赖：** 可信切割师、可追踪原石库存、跨境运输方案、书面服务条款与试单预算。
- **设计来源：** [领域词汇](../CONTEXT.md)与 [Rubiae 品牌基调与表达系统](rubiae-brand-foundation.md)。
