===================
Every piece exists as .svg (editable vector), .pdf (print-ready) and .png
(preview / on-screen). Print pieces carry 3 mm bleed and crop marks; the
trim size is in the file name where it is not standard.

  pouch-foil-artwork-gold      one-colour artwork for HOT FOIL only
  pouch-deboss-artwork-1colour one-colour artwork for deboss / engraving
  The two artwork files are the mark alone with the girdle seam WIDENED to
  1.4 units. Everywhere else the seam is a 0.25-unit hairline, which is what
  you want on screen and in flat ink — but foil dies and deboss tooling close
  a seam that fine, so the physical artwork opens it up. Do not use these two
  files on screen; they will look like the stone is split.

PRINTING NOTES
  Paper: an uncoated stock suits this identity far better than gloss. 300-350
  gsm for cards and tags, 120 gsm for the letterhead.
  Colour: these files are RGB. Ask your printer to convert, or if they want
  CMYK give them Ruby as roughly C30 M100 Y75 K30 and check a proof — deep
  reds shift more than any other colour between screen and press.
  Foil: use Gold Leaf #C79A4B only as actual foil. In flat ink use Gold Ink
  #8F6A22 — the pale gold is a 2.3:1 contrast ratio and vanishes.
  One-colour jobs (embroidery, deboss, engraving, vinyl): use the files whose
  names say 1colour, and never scale the standard symbol below 40 px / 14 mm.
