## 设计定义

EMPYRA 网站采用冷调编辑叙事风格。它像一本正在展开的女性人物杂志，也像一张可信的宝石商品档案。画面需要安静、有生活痕迹、略带距离感；红宝石是全页唯一高饱和视觉焦点。

**Design Read：** 面向自主购石女性的高端宝石品牌首页，使用冷灰雨景、非对称编辑构图和克制商品信息。

- `DESIGN_VARIANCE: 7`：明显非对称，但信息仍容易理解。
- `MOTION_INTENSITY: 3`：以静态摄影和轻微反馈为主。
- `VISUAL_DENSITY: 3`：留白充足，一屏只承载一个主要情绪和一个主要行动。

## 设计原则

1. **场景先于陈列：** 宝石真实地落在桌面、窗边、书本或织物旁，成为生活场景的一部分。
2. **红色只属于宝石：** 页面主体使用冷灰、烟黑与深梅色。桌面宝石使用最鲜明的红色，不给背景、按钮或装饰增加同等饱和度。
3. **故事与事实并置：** 人物故事负责情绪入口，重量、价格、处理与报告状态负责可信度。两者不混写。
4. **不替女性解释：** 人物以背影、局部动作或生活痕迹出现。故事只使用顾客本人确认并授权的表达。
5. **保留真实质感：** 桌面、书边、织物和宝石接触阴影必须清楚。背景可柔焦，商品及其承托表面不可糊成背景纹理。
6. **用静物表达成长：** 首屏后的摄影通过钥匙、笔记、信纸、时间物件、雨具和工作工具等生活痕迹暗示选择与新阶段，不用人物表演、励志符号或字面化庆祝道具替顾客解释经历。
7. **主图按类型表达：** 网站 Hero 与品牌栏目首图继续使用真实生活关系。首饰商品主图可自然佩戴或别在衣领、外套和织物上；晶体标本可使用可信展示或观察环境。裸石与切磨原石不强制生活化场景，可直接使用日光或标准中性光的真实观察图，并辅以放大观察、紫外光、毫米参照和多角度影像。任何主图都不能替代完整商品证据图。

## 第一眼必须出现的画面

进入 B2C 首页后，首个绘制完成的视窗必须直接呈现批准参考图的画面关系。不得先出现开场动画、全屏 Logo、促销弹窗、自动播放视频或需要点击关闭的引导层。

首屏固定包含：

1. 左侧雨后窗面与城市虚景，承载品牌名、主标题、短说明和主要 CTA。
2. 中右侧成年女性背影，人物不直视镜头，手部不是视觉中心。
3. 下方有真实纹理的桌面、一本书或克制织物，以及一颗清楚对焦的裸石。
4. 右侧倾斜或错位的编辑式故事页，建立 `Stories` 的情绪入口。
5. 桌面红宝石是第一视觉焦点。尺寸保持真实，不加光晕、不放大、不制造发光效果。

### 首屏内容

- 品牌：`EMPYRA`，Logo 完成前可使用临时文字标。
- 主标题：`Choose a stone for the life you are shaping.`
- 短说明：`Natural gemstones, honestly described and chosen on your terms.`
- 主要 CTA：`Explore the stones`
- 商品信息：真实商品名称、重量、公开价格、状态和详情入口。
- 故事入口：`Empyra Moments`、`Her story, in her own words.`、`Read her moment`

如果首发时尚无获授权的真实顾客故事，故事页可以说明 Empyra Moments 的用途，但不得伪造人物姓名、经历、引语或照片。

## 首屏后的静物叙事

[EMPYRA 首页静物叙事长页示意](rubiae-homepage-still-life-concept-v5.png)记录已确认的全页摄影关系。它是网站设计蓝图，不是商品真实性证据。

### 人物边界

- 完整人物只出现在首屏，并保持不看镜头的成年女性背影。
- 首屏后的全页最多出现一次局部手部，用于观察、选择或处理宝石；不出现脸、第二个背影、街景人物或通用模特。
- “成长”由物品留下的痕迹承担，不依赖人物表情、姿势或励志式表演。

### 场景系统

首屏后的每个摄影场景都必须出现红宝石。可直接采用或延展以下已确认场景语言：

1. 冷灰石面、天然亚麻边缘与单颗切面红宝石，作为慢看宝石的安静微距。
2. 局部手部以镊子观察数颗小红宝石，强调选择、判断和事实。
3. 雨窗旁的笔记本、钥匙、旧表带与深梅色织物，加一颗小红宝石，暗示时间与新的阶段。
4. 雨伞、打开的信封、钢笔与钥匙，加一颗小红宝石，暗示作出决定和重新开始。
5. 无熟悉参照物的矿物表面与红宝石微距，承接事实、材质和证据层。

这些物品是开放的叙事词汇，不是顾客必须套用的人生标签。避免毕业帽、婴儿、礼盒、婚戒、皇冠、心形或其他替顾客直接命名经历的道具。

### 红宝石亮度与比例

- 红宝石在所有摄影场景中都是唯一高饱和焦点。通过清楚曝光、内部切面反射、通透度和克制高光提高可见度；不添加光晕、外发光、漂浮或霓虹红。
- 品牌示意中的红宝石色相以最新实拍中六颗宝石的综合色为方向：主体为冷调深莓红，中间调偏覆盆子红，暗部保留通透酒红厚度，只有直接受光切面呈亮玫红和克制白色高光。整体必须读成天然深红宝石，而不是均匀的亮粉红、荧光洋红、棕红或橙红。
- 实物照片受拍摄光线与白平衡影响，因此该色相只用于品牌方向校准，不构成精确商品颜色承诺。正式商品页仍以校色后的真实库存摄影为准，不通过后期把商品强行调整成示意色。
- 场景中出现书本、手、镊子、钥匙、手表或其他熟悉物品时，红宝石必须保持真实、合理的毫米级视觉比例，并保留接触阴影。
- 微距场景没有熟悉参照物时，可按画面平衡决定宝石占比，但仍需保持可信的材质、落点、边缘与阴影。

### 全页色温

- 全页统一使用雾灰、烟灰、纸白、墨色和深梅色，不在后续区块切换为暖米色主题。
- 轻微暖意只允许来自室内灯光、天然木材和红宝石反射；织物、纸张、石面和雨景继续保持冷灰基底。
- 红色不扩散到大面积按钮、背景或装饰。页面始终先读成冷灰叙事，再看到红宝石。

## 桌面端构图

首屏使用 `min-height: 100dvh`，推荐按 1440 × 900 的 16:10 视窗校准。

| 区域 | 实施要求 |
| --- | --- |
| 顶部导航 | 64-72 px 高，透明叠在画面上，桌面端单行显示 |
| 左侧文本 | 占视窗宽度约 38%，左边距约 6vw，位于窗面较亮区域 |
| 人物 | 位于 50%-76% 横向范围，保持背影和深梅色轮廓 |
| 桌面 | 占首屏下方约 25%-30%，纹理和近处边缘清楚对焦 |
| 故事页 | 从右侧进入，占宽约 31%-35%，可轻微倾斜但不能遮住桌面宝石 |

页面文字、按钮、商品信息和故事卡必须作为 HTML 交互层实现，不得烙进摄影底图。

## 色彩系统

以下色值作为前端起始令牌。正式开发时根据真实摄影做小范围校准，不改变冷灰基底和单一红色焦点。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--empyra-fog` | `#D4D7D7` | 窗光、浅背景、雾灰留白 |
| `--empyra-paper` | `#ECEDEC` | 故事页与浅色信息面 |
| `--empyra-ink` | `#261C25` | 主标题、深色按钮、重要文字 |
| `--empyra-plum` | `#30222E` | 人物服装、深层背景、悬停态 |
| `--empyra-ruby` | `#C5163C` | 桌面宝石及极少量文字强调 |
| `--empyra-ruby-deep` | `#71142D` | 宝石暗面、细线和辅助红色文字 |
| `--empyra-smoke` | `#707274` | 次级文字和分隔层 |

禁止大面积米色、旧金、棕褐色纸张和暖黄滤镜。禁止让按钮、背景与宝石争夺红色焦点。

`--empyra-ruby` 是界面强调色起点，不是商品颜色替代值。网站摄影以 `v5` 的实拍综合色关系校准，商品页则必须使用真实库存的校色影像；不得用 CSS 色值或统一调色把不同宝石改成同一种红色。

## 字体与文字层级

- 情绪标题：优先使用有编辑感、笔画克制的衬线字体。已授权时使用 Canela 或 Tiempos Headline；开源回退使用 EB Garamond。
- 功能文字：使用清晰的中性无衬线字体。已授权时使用 Söhne；开源回退使用 Geist。
- 主标题桌面端建议 `clamp(3rem, 5.2vw, 5rem)`，字重 400，行高 0.98-1.04。批准首屏允许三行排版，以保持参考图节奏。
- 正文建议 16-18 px，行高 1.45-1.6。商品事实建议 14-16 px，不使用极细字重。
- 英文为默认语言，提供荷兰语切换。正文不用全大写；栏目小标签最多少量使用。

## 导航与首屏交互

桌面导航固定为：`EMPYRA | Collection | Stories | How to Choose | About | For Trade | EN / NL`；荷兰文对应使用 `Collectie`。Collection 页面标题明确提及 stones 与 jewellery，规范路径为 `/collection`。四类固定按成品裸石、切磨原石、红宝石晶体标本、精选合作首饰排序，使用不翻译的 `loose-stones`、`ruby-rough`、`crystal-specimens`、`jewellery` 子路径和共享目录模板；荷兰文只增加 `/nl` 前缀。商品详情统一使用 `/products/{handle}`。现有 `/stones` 路径永久重定向，不保留重复规范页。

How to Choose 总入口依次呈现标题与短介绍、四个编辑式类别入口、跨品类共同原则；共同原则覆盖用途与吸引点、观察实物、阅读事实、区分证据和决定前提问。手机端类别入口使用四张通栏纵向入口，不使用横向轮播或紧凑 2×2 卡片。四类指南使用与 Collection 类别匹配的独立子路径，不使用自动推荐或封闭式折叠；每类指南保持简洁六段节奏，最多使用三个带编号的真实库存例子，每个例子说明一个有意义的差异。商品详情与对应指南双向连接；无库存指南不显示商品入口。简单解释图必须标为示意、非商品证据，生成图不得模拟商品裂隙、晶体或处理效果证据。

Collection 总入口只显示已有合格库存的类别，每类最多预览三件；库存仅一至两件时全部显示。更多商品进入该类别每页六件的后续编号分页，不使用无限滚动。每件宝石必须拥有同一实物、同一编号的多角度摄影资料；Collection 总入口可节制展示，完整日光或标准中性光、正背面、侧面、微距和比例参照在商品资料中可查看。裸石与切磨原石可补充紫外光和放大观察图，但必须标注观察条件，且不得暗示实验室结论。

- 导航高度不超过 72 px，文字在一行内完成。
- 首屏主 CTA 只使用 `Explore the stones`，避免同时出现含义相同的第二个按钮。
- 商品详情、Stories 和 For Trade 使用文字链接，不制造多个同等权重按钮。
- 页面载入只允许 300-500 ms 的淡入与 8-12 px 轻位移。宝石本身不闪烁、不呼吸、不漂浮。
- 悬停只改变文字、下划线或 1 px 位移。禁止视差滚动、横向滚动劫持和自动轮播。
- 所有动效遵守 `prefers-reduced-motion`，降级为静态显示。

## Stones 列表页面

- 已批准的视觉基准为 [EMPYRA Stones 生活化列表参考](rubiae-stones-lifestyle-list-approved-reference.png)。它固定版式与生活情境方向，不构成商品影像或商品事实证据。
- 每个 Collection 分类页每页连续展示六件商品；每件仍有独立详情页，但同页浏览不要求逐件打开。
- 页面开场比首页 Hero 更紧凑；标题、结果数量和筛选完成后，第一颗宝石必须进入首屏，不用大块空白把目录内容推到首屏以下。
- 每颗宝石先用横跨本组的归属行显示石种、编号和重量，再展开摄影与事实；不使用 `01 / 12` 一类装饰编号。事实直接进入摄影留下的负空间、同色灰面或功能性图注，不使用漂浮白卡和逐行分隔的长参数表。
- 保留一行一颗，但不得把同一左右图文结构机械翻转到底。目录按三种版式形成可重复节奏：大幅生活场景加窄事实栏；同颗微距与短视频组成的摄影组加紧凑事实；宽幅生活静物加底部图注。三种版式都必须先明确商品归属，并在手机端收束为照片、核心事实和详情入口的单列顺序。
- 图片与事实同等重要不表示机械各占一半：先以生活化摄影建立吸引力，再用紧凑事实说明石种、编号、重量、形状或切工、处理结果及证据来源、报告状态、预览状态和询问链接。
- 旧报纸感来自冷灰摄影、编辑式裁切、功能性图片说明、少量细线和不完全对称的构图，不使用泛黄、仿古字体、漂浮纸卡、密集报纸分栏、满屏纸纹或参数表格主导画面。
- 当前宝石使用 `Stones to discover / Stenen om te ontdekken`；售罄档案随后使用 `Chosen stones / Gekozen stenen`。获得公开授权的顾客赋名可作为售罄卡片标题，未授权时仍只显示事实身份。
- 顶部不设置包含全部商品的缩略目录，也不使用横向滑动商品条。标题附近只显示当前分类、筛选后的结果数量和筛选控件；未来出现独立饰品目录时以分类入口切换，分类无内容时不显示。
- 已确认的外部参考只借用明确原则：Mociun 用于结果数量、筛选结构及商品影像内的视频入口；Completedworks 用于确保每张照片与其标题、事实和状态形成清楚归属；Sotheby’s 用于大型目录的筛选、排序和秩序感。Gemfields 的图文配对只进入原型试验，不视为已批准定案；Apartamento 不作为旧报纸视觉参考。
- 桌面端保留一行一颗，但单颗故事版块不得像独立满屏页面；缩短垂直占用，使当前宝石阅读完成时仍能看到下一颗的明确线索。每颗照片、短视频与事实必须紧邻、对齐并形成不可拆分的一组；事实不得跨入、遮挡或靠近到足以误认成下一颗的画面。所有宝石共享连续的冷灰环境，背景、光线、桌面材质和阴影跨版块延续；摄影应预留与页面同色的真实负空间，使画面边缘自然消失。跨产品的柔和过渡只由这些环境元素承担，不使用内容互相叠压、人工四边羽化、整屏底色交替、横向硬边或大块留白。
- 每颗宝石可在自己的摄影区域内提供一段对应实物的短视频，入口明确写为 `Play video / Video afspelen`，并始终与该宝石编号处于同一组。视频由顾客主动播放，默认不自动播放、不作为跨产品背景；使用真实商品视频与真实静态封面，提供暂停控制并遵守 `prefers-reduced-motion`。
- 手机端同页纵向排列，每件固定为“类型适配主图、核心事实、详情入口”，不左右交错、不使用横向滚动，也不使用强制滚动吸附。核心事实位置保持一致，以支持快速扫视与前后比较。
- 分类筛选结果超过六件时使用明确的编号分页；保留筛选后的结果总数、当前页和总页数。分页链接可分享、可键盘操作，筛选条件与当前页进入 URL；不使用 `View more`、无限滚动或横向商品轮播。

## 商品详情页面

- 每件商品根据类型、颜色、形状、切工或天然形态、尺寸、类型适配主图和证据影像单独完成艺术指导，不把同一张商品详情构图机械套给全部库存。
- “独立生成”指在发布前使用该商品已核验的资料与真实影像单独设计、人工复核并保存为确定页面版本；不在访客打开页面时实时生成，也不让生成结果改写商品事实。
- 独立的是摄影选择、裁切、留白、图片组合和编辑节奏。所有商品仍共用稳定的交互与事实骨架：商品身份、状态、类型适配主图、图库、视频控制、必填事实、证据来源、报告、预览提示和联系入口的位置与语义必须可预测。
- 已确认采用混合型首屏：桌面端约 65% 为真实的类型适配主图，约 35% 为紧凑核心事实。首饰可用生活化摄影；裸石、切磨原石和标本可用日光、标准中性光或可信观察环境。首图无需滚动即可配合读取商品编号、重量、形状、切工或天然形态、处理信息及其证据来源、报告状态和预览状态。不得用未证实的故事替代事实。
- 35% 事实栏保持两个可见小组，而非参数墙或折叠面板：`This stone / Deze steen` 为编号、重量、形状和切工；`What is known / Wat bekend is` 为处理、报告状态和每项信息的证据来源。未知信息必须写 `Unknown / Onbekend`。
- 首屏后的相册采用纵向编辑式证据序列，不使用缩略图库或整齐图片网格。它依次提供同一实物的日光或标准中性光整体、微距或侧面组合、毫米参照、报告与可选短视频；裸石和切磨原石可增加紫外光及放大观察。每张图配功能性图注，说明视角、光源或观察方式；紫外与放大观察不替代实验室结论，主图也不替代证据影像。
- 公开预览期唯一的商品行动入口置于证据序列之后，使用安静的 `Ask about this stone / Vraag naar deze steen` 文字区；不在首屏重复，也不使用侧边常驻按钮。该区说明询问不锁定宝石、不形成订单或优先购买权，并且不显示交易功能或其暗示。
- 正式页面文字、事实、状态、链接和控件保持为 HTML；不得把商品编号、报告、处理、状态或 CTA 烙入生成图片。桌面端可按商品独立构图，手机端统一收束为身份、类型适配主图、核心事实、图库、报告和联系入口的单列顺序。
- 售罄后保留同一 URL、事实、影像和报告状态；取得公开赋名授权时，以顾客原文名称作为主标题，并继续显示 `Named by its owner`、石种、商品编号和 `Sold`。

### 商品详情页已批准的轻盈叙事方向

- 已批准的视觉基准为 [EMPYRA Stone Detail 轻盈编辑参考](rubiae-stone-detail-light-editorial-approved-reference.png)。它固定页面密度、明暗关系、观察叙事与证据入口的层级，不构成商品影像、报告或商品事实证据。
- 商品详情页的故事性来自同一颗宝石被观察和核验的过程：遇见、慢看、转动观察、确认尺度、核对证据、提出问题。不得为了增加故事性而虚构顾客经历、人生节点、引语、产地故事或商品结论。
- 桌面端只设置三个主要摄影时刻：类型适配主图、日光或标准中性光整体、微距与侧面组合。毫米参照与报告保留为紧凑的 `Further evidence / Meer bewijs` 证据入口；裸石和切磨原石可在其中增加紫外光、放大观察和真实视频。入口可使用小型真实预览，但不得各自扩张为满宽摄影段、等高图片墙或传统缩略图网格；打开后仍须能查看全部可用证据。
- 页面以雾白和中性纸白为主，建议视觉占比约 70%；柔和烟灰约 20%；深梅与炭灰约 10%，只用于首图阴影、少量文字强调和小型视频预览。冷灰应读成明亮、安静和有空气感，不得形成连续深灰摄影墙或压抑的实验室目录。
- 摄影段之间保留足够留白，形成“看一张、读一点、停一下”的节奏。事实文字、证据说明和询问区直接进入雾白背景，不使用漂浮卡片、连续深色横带、等高证据行或固定的左图右注模板。
- 首图最多出现一处局部成年人的手、镊子与放大镜，用于表达正在观察；后续证据区不重复人物或手部。道具保持少量、开放和功能性，不用礼盒、婚戒或带有指定人生含义的物件替顾客解释经历。
- 约 65/35 的首屏图文比例、两个可见事实组、必填事实、`Unknown / Onbekend`、证据来源、预览状态、末尾唯一询问入口及全部真实性边界继续生效；轻盈不等于删减关键事实或证据。
- 批准参考图中的首页语言成为详情页的综合色彩规则：冷灰只来自雨窗、炭灰桌面、织物和真实摄影的环境层；事实栏、证据说明和询问区保持干净的雾白／纸白。不得在页面分区之间加入人工灰雾、整体灰色蒙版、渐变过渡或为了“融合”而扩大灰色面积。
- 桌面首层保持左侧雨窗观察场景与右侧纸白事实栏的明确分区。两者的统一感来自相同冷色摄影、留白、克制细线和首页一致的排版，而不是弱化界线；首图中的手、镊子、放大镜、书与织物只服务于观察与尺度，不构成商品事实。
- 首图下方以纸白底连续呈现 `Evidence / Bewijs`：左侧短说明，中央依次为中性光整体和微距／侧面两个主要摄影时刻，右侧为紧凑 `Further evidence / Meer bewijs` 入口。该入口展开后才显示毫米参照、报告与可选真实视频；不得把三张主证据做成等高卡片网格。
- 参考图仅固定构图、层级、色温、留白和交互密度；图中宝石、文字、实验室状态及影像均为示意，正式页面必须替换为同一实物的核验资料与摄影。

## Stories / Moment 一体页面

- 桌面端使用一个直接可读的界面，不再设置独立封面或只含摘要的中间页。左侧窄栏以顾客确认的总结性标题和一句概括纵览全部已发布的非匿名 Moments，当前选择清楚高亮；右侧同时展示该 Moment 获授权的顾客物品／影像、署名与完整故事。
- 普通 Stories 页首次打开即显示第一篇或当前 URL 对应的非匿名完整故事。点击左侧标题后，右侧展台与全文同步切换，不再要求第二次点击进入详情；每个进入普通目录的非匿名 Moment 保留可直接访问和分享的独立 URL。
- 顾客故事是页面主角；正文不与商品事实并列，也不把商品参数穿插进叙事。页面不复制 Stone 页的 65/35 首屏，不设置商品事实栏或询问 CTA。
- 右侧“展台”是编辑式构图，不代表 EMPYRA 制作或销售画面中的饰品。物品或影像必须由顾客提供并授权，不得以生成饰品冒充真实顾客内容。
- 顾客不提供物品或影像时，右侧展台刻意保持空置，承载完整故事的纸白阅读面成为唯一展品；不补通用宝石图、生成象征物、装饰性道具或替代照片。空置是顾客选择的有效呈现，不作为内容缺失错误。
- 切换只使用克制的淡换和 8–12 px 轻位移，不自动轮播；鼠标、键盘与触摸均可选择故事，`prefers-reduced-motion` 下直接替换内容。
- 故事文字、目录控件与语言入口保持可选择、可读屏、可索引的 HTML。长故事自然纵向阅读，不再使用翻书页拆分正文。
- 非匿名 Moment 只有取得故事与宝石关联授权时，全文结束后才显示一张紧凑 Stone 档案卡。卡片包含真实宝石照片、获授权公开名称或石种、商品编号、`Sold` 状态和档案链接。
- 匿名 Moment 永不公开 Stone 关联，即使后台保留内部关联记录或已取得独立关联授权，也不显示 Stone 档案卡、宝石照片、名称、编号、石种或链接。只有顾客另行批准改为非匿名发布，并同时具备故事与宝石关联授权，才可公开这些关联。
- 旧 [Stories 与 Moment 翻书页参考](rubiae-stories-moment-book-approved-reference.png) 仅保留为历史探索记录；其封面、两步进入故事与翻书页模型已被 2026-07-30 的一体式纵览／展台决定取代，不再作为实现基准。
- 手机端进入普通 Stories 即显示第一篇或当前 URL 对应的非匿名完整故事，不先出现独立目录页。Moment 上方使用紧凑的当前标题＋`All stories / Alle verhalen` 选择器；点击后从底部打开故事抽屉，选择标题即关闭抽屉、更新独立 URL，并在同一单列阅读面显示对应的授权物品／影像或空展台与完整故事。抽屉只用于切换，不是阅读前置步骤；不把桌面左右布局等比缩小，不使用横向滑动故事条。控件支持触摸、键盘、焦点返回、明确关闭和减少动效。
- 匿名 Moment 不出现在桌面左侧目录或手机底部抽屉，不以普通目录项暴露标题与概括。至少有一篇合格匿名故事时，它们只由始终可见的独立邀请 `Encounter an anonymous Moment / Ontmoet een anoniem moment` 随机发现；没有合格匿名故事时，整个邀请隐藏，不显示失效按钮或空状态文案，普通 Stories 保持不变。激活邀请后，桌面右侧展台或手机单列阅读面原位替换为匿名故事，不弹出长文模态框，不经过独立中间页。匿名故事没有公开固定链接，也不改变当前非匿名 Moment URL；刷新后恢复该 URL 对应的普通故事。匿名正文不进入 sitemap、页面 metadata 或搜索引擎收录，但公开内容仍可能被复制、保存或截图。匿名故事统一使用英文标题 `An Empyra Moment`、荷兰语标题 `Een Empyra Moment`，不显示顾客或故事特有标题；署名在英文页只显示 `Anonymous`，荷兰语页只显示 `Anoniem`，不显示姓名、缩写、自选化名、城市、年龄或购买时间。匿名发布前由 EMPYRA 检查正文中的姓名、联系方式、账号、精确地点、单位、学校、日期、顾客／订单／宝石标识及可能通过组合识别个人的罕见经历，只做保留原意所需的最小删除或概括，并由顾客确认最终脱敏原文与页面预览；自动脱敏或顾客单独自检不能替代此流程。若无法在不实质改变经历、语气或含义的情况下把可合理预见的识别风险降下来，则不以匿名方式发布。匿名图片逐张清除 EXIF、IPTC、XMP、GPS、嵌入预览和原公开文件名，并检查人脸、姓名、地址、车牌、屏幕、文件、明显身体特征及可识别住宅或工作地点。只有在不改变含义或误导画面的前提下才裁切或遮挡识别区域，并由顾客确认最终图与页面预览；无法安全处理时不用该图，改为空展台，不补通用或生成替代图。匿名状态下不公开任何 Stone 关联；内部记录可保留，但公开 Stone 卡、照片、名称、编号、石种或链接须先另行改为非匿名发布并具备关联授权。桌面普通目录继续可见但不错误高亮某个非匿名项；手机抽屉不变。`Back to stories / Terug naar verhalen` 返回触发前的非匿名故事。匿名全文末尾提供 `Encounter another anonymous Moment / Ontmoet nog een anoniem moment`；只有访客主动激活才在原阅读面替换故事，不在读完、滚动或等待后自动继续。至少有两篇合格匿名故事时不立即重复当前故事，连续遇见期间始终保留最初的非匿名返回目标。只有一篇合格匿名故事时，主邀请仍可打开该故事，但文末不显示“再遇见”控件，也不显示失效按钮，只保留返回普通故事的入口。邀请必须有明确文字、可见焦点并支持鼠标、触摸与键盘；不隐藏在悬浮物件中，不要求等待或抢点流星、纸飞机等定时事件。入口造型与装饰动效仍未定稿；随机只是氛围，不代替正文、影像与 metadata 的真实脱敏。

## 响应式规则

### 桌面端，1200 px 及以上

完整还原批准参考图：左侧文字、中央人物、前景桌面、桌面宝石和右侧故事页同时出现在第一视窗。

### 平板，768-1199 px

保留人物、桌面宝石和故事页。缩小主标题与故事页，不能通过压缩使导航换行。空间不足时把次级导航移入菜单。

### 手机，小于 768 px

使用单独制作的竖版摄影裁切，不把桌面端截图等比缩小。第一视窗必须保留雨窗、人物背影、桌面宝石、品牌名、标题和主要 CTA。大型故事页移到首屏之后，首屏仅保留 `Stories` 入口。桌面宝石位于下方三分之一范围，不能被浏览器工具栏或 CTA 遮挡。

## 图片制作与真实性

- 全页场景、人物边界、宝石亮度、比例与实拍色相方向以 [EMPYRA 首页静物叙事长页示意](rubiae-homepage-still-life-concept-v5.png) 校准；正式制作时重新拍摄或以真实库存影像替换。
- 网站主视觉与品牌栏目首图采用生活化摄影。商品列表与详情首图按类型选择：饰品优先自然佩戴或别在衣物上的状态；晶体标本使用可信展示或观察环境；裸石和切磨原石可直接使用日光或标准中性光观察图，不强制加入人物或生活道具，并保留可信比例。
- 参考图只作设计蓝图。正式 Hero 需要重新拍摄或使用已核验的真实库存影像。
- 桌面端建议准备 2880 × 1800 AVIF 主图；移动端另备至少 1440 × 1800 的竖版构图。
- 商品页另有标准光、微距、多角度和特征披露影像。情绪 Hero 不能代替商品证据。
- 每件商品以类型适配主图建立第一印象，以日光或标准中性光整体、毫米参照、多角度、微距和可选短视频支持事实核验；裸石与切磨原石可增加紫外光和放大观察图。全部影像必须使用同一实物并绑定同一商品编号，紫外或放大观察不得升级为实验室结论。
- 场景摄影可以控制光线和构图，但不能改变宝石颜色、净度、切工、内含物或尺寸观感。
- AI 生成图不得作为商品真实性证据，也不得绑定真实商品编号、证书或价格发布。
- 每颗可购买商品的相册至少包含中性光整体图、毫米参照图、正面、背面、侧面、微距和短视频；影像与商品编号及独立报告一致。
- 商品影像只允许不改变事实的曝光与白平衡校正。AI 场景图、合成宝石、改变色相或净度的修饰不得进入商品相册。

## 前端组件边界

| 组件 | 职责 |
| --- | --- |
| `SiteHeader` | 品牌、主导航、语言切换与移动菜单 |
| `HomeHero` | 首屏布局、摄影底图和响应式艺术指导 |
| `HeroCopy` | 标题、短说明与唯一主要 CTA |
| `StoneSpotlight` | 从库存数据读取商品事实和状态 |
| `StoneStatus` | 只使用 `Available`、`Reserved`、`Overseas inventory`、`Enquire`、`Sold` |
| `StoneFilters` | 首发仅含状态、重量、处理、价格排序和清除筛选 |
| `CartNotice` | 说明购物车不锁货，并在结账前触发库存复核 |
| `OrderSummary` | 显示商品、含税价格、保险配送、总价、状态、交期与条款入口 |
| `PaymentStatus` | 分别呈现 `Paid`、`Pending`、`Failed` 及下一步 |
| `PreviewNotice` | 说明尚未开放购买，并在预览期替代全部交易入口 |
| `InterestForm` | 仅收集非约束性兴趣登记或商品问题，不锁货、不收订金 |
| `InterestConfirmation` | 双语说明不锁货、不成单、无需付款及回复时限 |
| `MomentSheet` | 从已授权故事数据读取标题、摘要和链接 |

摄影资产、库存数据和故事数据必须分离。缺少真实商品或授权故事时显示诚实的空状态，不把示意内容带入正式环境。

公开预览期隐藏 `CartNotice`、`OrderSummary` 与 `PaymentStatus`，商品状态统一为 `Preview — not yet available for purchase`，不显示价格、`Available` 或 `Reserved`；完整交易组件只在未发布环境验收。

`InterestForm` 仅包含姓名、邮箱、宝石编号、首选语言和可选留言。开售通知采用独立且默认不勾选的双重确认选项。公开内容页可索引；确认页、隐藏交易路径、测试主题与客户数据页面均 `noindex`。

## 验收标准

1. 1440 × 900 首次打开时，无需滚动即可看到参考图中的五个核心元素和主要 CTA。
2. 桌面宝石是唯一高饱和焦点；桌面纹理、宝石切面和接触阴影清楚。
3. 页面没有大面积米色、金色装饰、宝石光晕、通用笑脸模特或模板化三卡片布局。
4. 390 × 844 首屏仍能看到标题、CTA 和桌面宝石，文字不压住商品。
